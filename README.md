# 番茄钟（桌面番茄钟）

一个简洁的 Electron 桌面番茄钟：专注 / 短休息 / 长休息循环，置顶小窗、提示音、系统通知、最小化到托盘。

## 运行

```bash
npm install
npm start
```

## 使用说明

| 操作 | 方式 |
| --- | --- |
| 开始 / 暂停 | 点击「开始」按钮，或按空格 |
| 重置当前阶段 | 点击 ↺，或按 `R` |
| 跳过到下一阶段 | 点击 ⏭，或按 `S` |
| 置顶 / 取消置顶 | 点击 📌 |
| 最小化 | 点击 ─（保留在任务栏，计时继续） |
| 退出 | 点击 ✕ 或 Alt+F4 |
| 托盘 | 托盘图标右键可显示/隐藏、开始/暂停、退出 |

## 功能

- 25 分钟专注 → 5 分钟短休息，每 4 个番茄后进入 15 分钟长休息（均可在「设置」中修改）。
- 阶段结束自动播放提示音 + 系统通知，可自动进入下一阶段。
- 进度环随剩余时间变化，颜色随阶段切换（专注红 / 短休绿 / 长休蓝）。
- 设置保存在本地（`localStorage`），下次启动自动恢复。

## 打包成可执行文件（可选）

```bash
npm install --save-dev electron-builder
npx electron-builder --win
```
